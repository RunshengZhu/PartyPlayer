# 舞会音乐播放器 (Party Player)

专为舞会场景设计的音乐播放器：按舞种管理音乐、随机生成歌单、限时播放 + 渐弱 + 歌曲间隔。

**零第三方依赖**：基于 Go 标准库编写，音频由浏览器播放，一条交叉编译命令即可产出
Windows / macOS / Linux 的**单可执行文件**——无需安装 Python、无需装任何库，双击即用。

## 快速开始

1. 启动（任选其一）：
   - 直接运行已编译好的可执行文件（见 `dist/`，macOS 用户注意 arm64 = Apple Silicon，amd64 = Intel）；
   - 或从源码运行：`go run .`
2. 程序会自动打开浏览器页面（默认 `http://127.0.0.1:8765`）。
3. 首次使用在页面里点「📁 选择目录」弹出**系统文件夹选择框**（macOS Finder / Windows 资源管理器），
   也可以手动粘贴路径，或启动时指定：

   ```bash
   ./party-player -lib "/Users/xxx/Music/舞会"       # macOS
   party-player.exe -lib "D:\Music\舞会"             # Windows
   ```

## Android 版使用

安装 APK 后点「📁 选择目录」会拉起**系统文件管理器**的目录选择器。
首次使用需在系统设置中允许本应用「所有文件访问」（选择目录时会自动跳转授权页），
因为曲库需要按真实路径读取。界面已针对手机屏幕适配（标签页布局、大触控区）。

### 音乐库目录结构

音乐库根目录下的**每个一级子目录视为一个舞种**，目录内的音频文件自动归入该舞种：

```
舞会/
├── 华尔兹/  月亮河.mp3, 蓝色多瑙河.mp3
├── 探戈/    自由探戈.mp3, 闻香识女人.mp3
├── 恰恰/    恰恰恰.mp3
├── 伦巴/    恋人浪漫.mp3
├── 桑巴/    ...
├── 牛仔舞/
├── 快步舞/
└── 狐步舞/
```

支持格式：mp3 / wav / flac / ogg / m4a / aac / opus（浏览器原生支持的格式）。

## 功能

- **音乐库扫描**：目录名自动识别舞种（中英文别名归一），按**摩登 / 拉丁 / 交谊舞 / 其它**分组
  （组内按赛事 A 组顺序），支持舞种内嵌套子目录，可随时重新扫描
- **歌单是独立管理对象**：「歌单管理」独立页面——每个歌单记录自己的**挂载曲库目录**，
  载入时自动切换曲库；支持保存 / 载入 / 删除 / 导出（M3U/CSV/PLS/JSON）/ 导入
- **随机生成歌单**：为每个舞种设数量，支持交错排列（同舞种不相邻）与按舞种分组
- **舞会播放控制**：单曲限时到点自动渐弱切歌（0 = 完整播放）、歌曲间隔、
  播放页内嵌设置条即改即存（与点播设置相互独立）
- **添加乐曲文件树**：按挂载曲库的层级目录浏览，逐曲加入歌单
- **点播模式**（独立页面，与舞会歌单平行）：
  舞种卡片分栏点播、曲目列表指定播放、多舞种轮次按编辑顺序播放、
  舞种名称语音播报、舞种间隔可调，播完即停
- **歌单图片**：一键把当前歌单排成 A4 300dpi 精美图片（按编辑顺序平铺、
  曲名后附舞种标签、舞者线稿水印、描边高可读、背景明度自适应），
  内置 5 款经典背景，支持导入自定义图片背景，下载 PNG 即可打印或分享
- **手机接入**：`-listen 0.0.0.0` 启动后展示二维码，同一 Wi-Fi 的手机扫码看同一页面
- **使用说明**：内置带标注截图的分场景说明书页面

## 命令行参数

| 参数 | 说明 | 默认 |
|---|---|---|
| `-lib` | 音乐库根目录 | 页面中设置 |
| `-port` | HTTP 端口（被占用自动顺延） | 8765 |
| `-listen` | 监听地址；`0.0.0.0` = 允许局域网设备（手机）访问 | 127.0.0.1 |
| `-data` | 数据目录（配置/歌单） | 用户配置目录下 `PartyPlayer` |
| `-no-browser` | 不自动打开浏览器 | 关闭 |
| `-version` | 打印版本信息后退出 | |
| `-h` | 查看帮助 | |

**版本号与发布**：构建产物与程序内版本均带构建时间（如 `v0.1.0-20260920-1830`），
由 `build.sh` / `build-apk.sh` 自动注入，「使用说明」页底部展示。
测试服发布采用**固定链接直接替换**：`./build.sh v0.1.0-xxx` 指定与上次相同的版本号构建后，
按原文件名上传覆盖即可，下载链接保持不变。

播放页面默认只监听 `127.0.0.1`，局域网无法访问；
以 `-listen 0.0.0.0` 启动时，页面顶栏出现「📲 手机接入」：
同一 Wi-Fi 下的手机扫码或输入地址即可打开同一播放页面（适合舞会现场多人看歌单）。

## Android 版（同一套代码）

`build-apk.sh` 会把同一个 Go 服务器编译为 android/arm64，打包进极薄的 Java 壳：

```
Go 服务器（libpartyplayer.so，随 APK 携带）
  └─ 由前台服务在应用内 exec，监听 127.0.0.1 + 0.0.0.0
       └─ WebView 加载播放页面（同一套 web/ 界面）
```

- 前台服务 + 常驻通知保证锁屏后播放不中断；通知带「停止」按钮
- 局域网设备同样可扫码接入手机上的服务器
- 业务逻辑与桌面版**完全同源**，没有第二份实现

构建依赖：JDK 17+、Android SDK（platform 35 / build-tools 35）、Gradle 8.9+：

```bash
./build-apk.sh      # 产出 dist/party-player-android-arm64.apk，直接安装到 arm64 真机
```

工程位于 `android/`（纯 Java + WebView，无 AndroidX/Kotlin 依赖）。
iOS：Go 代码可直接编译为 ios/arm64（需 Mac + Xcode），做法同为
「内嵌本地服务器 + WebView」，但需要 Xcode 工程与签名，未包含在本仓库中。

## 快捷键

`空格` 播放/暂停 · `←`/`→` 快退/快进 5 秒 · `PageUp`/`PageDown` 上一首/下一首

## 从源码构建

要求 Go 1.25+（仅需构建机安装，最终用户零依赖）：

```bash
git clone <本仓库>
cd player
./build.sh          # 产出 dist/ 下的 macOS(arm64+amd64) / Windows(amd64+386) / Linux 单文件
```

Windows 版使用 `-H=windowsgui` 链接参数，双击运行不会弹出黑色控制台窗口。

## 项目结构

```

├── main.go                    # 入口：参数、监听、自动打开浏览器

│   ├── app.js                 # 播放器逻辑：限时/渐弱/间隔/自动切歌
│   └── style.css
├── internal/
│   ├── app/                   # 状态与业务：音乐库、歌单、设置、持久化
│   │   ├── app.go
│   │   ├── library.go
│   │   ├── playlist.go        # 含 M3U/PLS/CSV 导入导出
│   │   └── playlist_test.go
│   └── server/

```

## 与旧版（Python/pygame 版）的差异

| | 旧版 party-player v0.x | 本版 |
|---|---|---|
| 运行依赖 | Python 3.12 + pygame + mutagen + tkinter | 无（单可执行文件 + 系统浏览器） |
| macOS 兼容性 | pygame/SDL 二进制不兼容新版 macOS 会启动失败 | 无本机音频库，不受影响 |
| 跨平台产物 | 需逐平台打包 | 一条命令交叉编译 |
| 音频解码 | SDL Mixer | 浏览器（格式支持更广） |
| 歌单格式 | JSON / CSV / M3U / PLS | 同左（并兼容旧版 CSV） |
